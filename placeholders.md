# PlaceholderAPI

Registered automatically when PlaceholderAPI is installed.

| Placeholder | Value |
|---|---|
| `%omniguard_attack_mode%` | `on` / `off` |
| `%omniguard_monitor_mode%` | `on` / `off` |
| `%omniguard_lockdown%` | `on` / `off` |
| `%omniguard_pps%` | Packets per second (server) |
| `%omniguard_blocked%` | Total blocked actions |
| `%omniguard_kicks%` | Total kicks |
| `%omniguard_dupes%` | Dupes caught |
| `%omniguard_tracked_items%` | Item identities in the ledger |
| `%omniguard_player_vl%` | Sum of the player's current violation levels |
| `%omniguard_player_brand%` | The player's client brand |
