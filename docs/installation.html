Installation#

Requirements#

Supported
Server Spigot, Paper, Purpur, Folia
Minecraft 1.17.1 → 26.x
Java 17+ (Minecraft 26.x itself needs Java 25)
Required plugin PacketEvents 2.14+ (free)
Works next to ViaVersion, ProtocolLib, PlaceholderAPI, LuckPerms, anticheats

Steps#

  1. Stop the server.
  2. Download PacketEvents for your platform (Spigot/Paper build) and copy it into plugins/.
  3. Copy OmniGuard-x.y.z.jar into plugins/.
  4. Start the server. You should see OmniGuard x.y.z enabled on Paper in … ms.
  5. Run /og doctor in game or in the console.

Never install or update OmniGuard with /reload or plugin managers. Netty handlers must be injected while the server starts.

Bedrock players (Geyser / Floodgate)#

Fully supported. Floodgate name prefixes (. and * by default, see login-guard.bedrock-prefixes) are accepted, Geyser's local connections are never rate-limited, and Geyser-translated inventory clicks are not judged by Java-only rules.

Behind a proxy (BungeeCord / Velocity)#

checks.connection-flood.behind-proxy: auto detects forwarding (spigot.yml bungeecord, Paper Velocity settings). In proxy mode, per-IP connection limits switch off because all traffic comes from the proxy. Every other protection keeps working, including per-IP login limits, which use the forwarded player IP.

Updating#

Replace the jar and restart. New config keys fall back to their defaults until you add them. /og reload lists anything it had to fall back on.
