All checks#

OmniGuard ships 35 checks. Each one is configured under checks.<id> and can be bypassed with omniguard.bypass.<id>. Common keys: enabled, cancel, alert-vl, max-vl, decay-per-second, kick, instant-kick, commands (see Configuration).
